eMAG 卖家工具箱 1.0.7
构建日期：2026-11-12

安装（推荐使用 Chrome 120 或更新版本）
1. 将整个 ZIP 解压到固定位置，例如 D:\BrowserExtensions\eMAG。不要在压缩包中直接打开。
2. 在 Chrome 地址栏输入 chrome://extensions 并打开。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本说明旁边的 extension 文件夹。
   正确的文件夹内应直接看到 manifest.json、popup.html、assets 和 icons。
5. 安装后不要删除或移动该文件夹，浏览器会继续读取其中的文件。
6. 刷新已打开的 eMAG 商品页，点击右侧“卖家助手”。
7. 点击浏览器扩展菜单，可将“eMAG 卖家工具箱”固定到工具栏；工具栏按钮可打开标签与 DoC 表单。

使用
- 商品透视适用于 https://www.emag.ro/ 的商品详情页。
- 标签和 DoC 中的企业资料需要使用者自行填写。
- 每个使用者的数据保存在自己的浏览器中，安装包不包含发包人的浏览器表单数据。
- 导出标签后，打印请选择“实际大小 / 100%”。
- 接收方无需安装 Node.js、npm 或其他开发工具。

更新
1. 关闭正在打开的插件面板。
2. 将新版安装包中的 extension 内容完整替换到原安装位置，保持文件夹路径不变。
3. 打开 chrome://extensions，找到本扩展并点击重新加载（刷新图标）。
4. 刷新 eMAG 商品页面。不要卸载后重装，以免清除已保存的数据。

说明
- ZIP 采用开发者模式安装，不会自动更新。
- 企业管理的浏览器如禁用开发者模式，需要联系管理员采用允许的分发方式。
- 第三方字体与图标的来源及许可见 extension\licenses。
